## About

Rhenius), பொதுவாக "இரேனியஸ் ஐயர்", "இரேனியஸ் ஐயர்" என்று அழைக்கப்படுபவர். நவம்பர் 5, 1790-ல் ஜெர்மனியில் (அன்றைய பிரஷ்யா) பிறந்தார். லண்டனில் மிஷனரி சங்கத்தில் (Church Missionary Society - CMS) பயிற்சி பெற்ற இவர், 1814-ம் ஆண்டு தனது 24-வது வயதில் இந்தியா வந்தடைந்தார். முதலில் சென்னையில் தனது பணியைத் தொடங்கிய இவர், மிகக் குறுகிய காலத்திலேயே தமிழை முறையாகக் கற்றுத் தேர்ந்தார். அக்காலத்தில் இருந்த விவிலிய மொழிபெயர்ப்பு கடினமான நடைமுறையில் இருந்ததால், சாமானிய மக்களும் எளிதாக புரிந்துகொள்ளும் வகையில் 1833-ல் புதிய ஏற்பாட்டைத் தமிழில் மொழிபெயர்த்தார் (இதுவே நீங்கள் தற்போது பயன்படுத்தும் 1836-ம் ஆண்டு பதிப்பிற்கு அடிப்படை). இவர் எழுதிய "A Grammar of the Tamil Language" (1836) என்ற புத்தகம் தமிழ் இலக்கணத்தை ஆங்கிலேயர்களும் தமிழர்களும் எளிதாகக் கற்க மிகவும் உதவியாக இருந்தது. 1820-ல் இவர் திருநெல்வேலிக்கு மாற்றப்பட்டார். இவருடைய காலத்தில்தான் திருநெல்வேலி ஒரு மிகப்பெரிய கிறிஸ்தவ மையமாக உருவெடுத்தது. ஆயிரக்கணக்கான மக்கள் இவரது போதனையினால் கிறிஸ்தவத்தைத் தழுவினர். பல பள்ளிகளையும், ஆலயங்களையும் நிறுவினார். அவரைத் திருநெல்வேலியின் நவீன சிற்பி என்றே அழைக்கலாம். பாலையங்கோட்டையில் அவர் கட்டிய புனித திரித்துவ தேவாலயம் (Holy Trinity Church) இன்றும் புகழ்பெற்றது. ஜாதி பாகுபாடுகளை களைந்து, ஒடுக்கப்பட்ட மக்கள் கௌரவமாக வாழ்வதற்காக "தர்மபுரி", "நேசபுரம்" போன்ற பல மாதிரி கிராமங்களை உருவாக்கினார். சுதேசி ஊழியர்களை உருவாக்குவதில் அதிக கவனம் செலுத்தினார். தொடர்ச்சியான உழைப்பினால் உடல்நலம் பாதிக்கப்பட்டவர், ஜூன் 5, 1838-ல் தனது 47-வது வயதில் காலமானார். அவரின் உடல் பாலையங்கோட்டையில் உள்ள புனித திரித்துவ தேவாலய வளாகத்தில் அடக்கம் செய்யப்பட்டுள்ளது. இரேனியஸ் ஐயர் ஒரு வெளிநாட்டவராக இருந்தாலும், தமிழை ஒரு தாய்மொழியாக நேசித்து, அதன் வளர்ச்சிக்கும், பாமர மக்களின் முன்னேற்றத்திற்கும் தனது வாழ்வையே அர்ப்பணித்தவர்.
